# MMA Login UI Demo

Ứng dụng demo UI đăng nhập theo thiết kế yêu cầu, chỉ có phần giao diện và không có chức năng xác thực.

## Cài đặt

1. Mở terminal trong thư mục `mobile-app`
2. Chạy `npm install`

## Chạy trên iPhone (Expo)

1. Chạy `npm start`
2. Mở ứng dụng Expo Go trên iPhone
3. Quét QR code hoặc chọn chuỗi kết nối phù hợp

> Lưu ý: Cần cài Expo CLI nếu muốn chạy trên máy tính: `npm install -g expo-cli`
